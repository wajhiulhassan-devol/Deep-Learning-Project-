# Deep-Learning-Project-
TalentPulse AI - Employee Performance Prediction System
In this project, I upgraded my Machine Learning project into a Deep Learning based web application using ANN and CNN models.

Features:
* Employee performance prediction
* Deep Learning concepts implementation
* Modern web dashboard
* Model comparison and visualization

Technologies Used:
Python, TensorFlow, FastAPI, Pandas, Scikit-learn

This project helped me understand how Deep Learning can improve prediction systems compared to traditional ML models
